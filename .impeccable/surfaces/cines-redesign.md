# Cines PY redesign surface brief

- **Mode:** Operate. Visitors need to find a film, cinema and published session quickly and comfortably.
- **Audience:** Cinema-goers in Paraguay; mobile-first.
- **Source of truth:** Real titles, posters, genres, cinema names, links and raw session strings from the scraper; extra facts only from verified official pages.
- **Hosting:** GitHub Pages project site at `https://yosoymitxel.github.io/cines.com.py/`.
- **Visual direction:** Modern immersive cinema portal, dark cinema canvas (`#0C0F14`), elevated surface cards (`#141824`), cinema red accent (`#E50914`), cinema gold highlights (`#F5C518`), poster-forward hierarchy, clean tabular showtimes.
- **Rejected direction:** Outdated table layouts and artificial paper-pamphlet / brutalist zine aesthetics with oversized Impact fonts and postage stamps.
- **Anti-slop:** Follow `docs/ANTI-SLOP-UI.md`; no repetitive arrow spam on every link, no generic gradients, glass, decorative stamps or motion loops.
- **Motion:** Short, purposeful micro-interactions; respect reduced motion.
- **Finish:** Browser validation at 1440, 1024, 768, 390 and 360 px; verify all routes, menu, search, filters, keyboard use, no horizontal overflow, SEO and GitHub Pages canonical paths.

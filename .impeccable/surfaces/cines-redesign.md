# Cines PY redesign surface brief

- **Mode:** Operate. Visitors need to find a film, cinema and published session quickly.
- **Audience:** Cinema-goers in Paraguay; mobile-first.
- **Source of truth:** Real titles, posters, genres, cinema names, links and raw session strings from the scraper; extra facts only from verified official pages.
- **Hosting:** GitHub Pages project site at `https://yosoymitxel.github.io/cines.com.py/`.
- **Visual direction:** Editorial cinema programme / cultural listings, warm paper, ink-blue black and restrained vermilion. Large condensed display type, real posters, asymmetrical lead story, direct lists for venues and showtimes.
- **Rejected direction:** The previous dark-green, rigid, uniform composition. Do not restore it.
- **Anti-slop:** Follow `docs/ANTI-SLOP-UI.md`; no template cards, arbitrary badges, decorative icons, fake stats, gradients, glass, excessive radius or motion loops.
- **Motion:** Short, purposeful entrance and hover feedback only; respect reduced motion.
- **Finish:** Browser validation at 1440, 1024, 768, 390 and 360 px; verify all routes, menu, search, filters, keyboard use, no horizontal overflow, SEO and GitHub Pages canonical paths.
